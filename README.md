# Jimmy

Landing page for Jimmy, an AI assistant concept that takes care of the admin side of university life. Built for HackLBS 2026 at London Business School.

**Live:** https://hacklbs2026-jimmy.vercel.app

## What is in this repo

A single static page (`index.html`) with no build step and no dependencies. It covers the problem, the features, how it works, pricing and a waitlist section, plus a link to try the Telegram bot.

## Run locally

Open `index.html` in a browser.
